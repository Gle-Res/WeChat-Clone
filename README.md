# WeChat-Clone

一款用于在同一台设备上运行两个微信客户端的工具。

## 项目简介

WeChat-Clone 通过修改微信客户端的包名并重新签名，使同一台设备可以安装两个独立的微信应用，从而实现双账号同时在线。

## 功能特点

- 支持在同一台设备上运行两个微信账号
- 工作号与生活号分离
- 无需反复登录和退出
- 安装配置简单

## 使用方法

1. 下载最新 Release 中的 IPA 文件。
2. 使用签名工具（如轻松签、AltStore 等）对 IPA 进行签名。
3. 安装到设备上。
4. 打开应用，登录第二个微信账号。

## 注意事项

- 使用前请确保已安装官方微信客户端。
- 本工具仅修改包名，不修改微信客户端本身的功能代码。
- 需要自备签名证书或使用免费签名服务。
